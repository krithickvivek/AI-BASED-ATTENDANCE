# 📌 Project Overview

The **AI-Based Classroom Attendance System** is an intelligent attendance management solution that automatically detects and recognizes student faces from classroom images using Artificial Intelligence and Computer Vision.

The system reduces manual attendance time, improves accuracy, and generates attendance reports automatically.

---

# 🚀 Features

✅ Face Detection using AI  
✅ Student Face Recognition  
✅ Automatic Attendance Marking  
✅ Present / Absent Status Generation  
✅ CSV Attendance Export  
✅ Classroom Group Image Support  
✅ Fast and Accurate Recognition  
✅ Simple Google Colab Implementation
